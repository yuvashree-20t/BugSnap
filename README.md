# BugSnap

AI-Powered Bug Reporting Platform.

## Overview

BugSnap helps developers and testers generate structured
software bug reports using screenshots and AI analysis.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Google Gemini API

## Features

- Screenshot-based bug reporting
- AI-generated bug descriptions
- Bug report management
- Dashboard and analytics
- Markdown export
